# Related work

Projects and papers that explore similar ideas (not affiliated; listed for context):

- `DearVa/ida_copilot`: GPT agent plugin for IDA Pro.
- `atredispartners/aidapal`: IDA Pro plugin using a locally run fine-tuned model.
- `mrexodia/ida-pro-mcp`: MCP server for IDA Pro.
- `radareorg/r2ai`: AI integration for radare2.
- MALSIGHT (arXiv:2406.18379): iterative binary malware summarization.
- FidelityGPT (arXiv:2510.19615): retrieval-augmented correction of decompilation distortions.
- D-LiFT (arXiv:2506.10125): quality-driven fine-tuning of LLM decompiler backends.

`retriage` differs mainly in its emphasis on a hardened, backend-agnostic tool layer, auditable transcripts and ground-checked reports, and in using only open-source tooling.
